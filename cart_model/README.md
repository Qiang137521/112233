# 三层小推车儿童玩具模型（高 200 mm，免螺丝）

只有 **2 种零件、5 个打印件**，`stl/` 里已摆好打印朝向，**不需要支撑**。

| 文件 | 数量 | 尺寸 (mm) | 说明 |
|---|---|---|---|
| side_frame_x2.stl | 2 | 200×69×8 | 侧框：两根立柱 + 弧形把手 + 两个假轮子一体，平放打印（假轮子不会转） |
| basket_x3.stl     | 3 | 115×65.6×26（含插销） | 篮子：R10 圆角、外壁藤编纹、网格底，两端各 2 根 Ø4 插销，开口朝上打印 |
| assembly_preview.stl / .glb | – | 116×69×200 | 组装预览，不用打印 |

## 怎么做到不用螺丝
原物在立柱上打螺丝的位置，改成了**篮子两端伸出的 Ø4 小圆柱插销**，对应侧框立柱上的 Ø4.2 通孔。
插销末端带倒角，用手按进去就靠摩擦卡住，不用工具。

## 组装（1 分钟）
1. 一片侧框平放在桌上，孔朝上。
2. 三个篮子一端的插销分别插进这片侧框的 6 个孔里。
3. 第二片侧框对准另一端的 6 根插销，从上面盖下来，压到底。
4. 翻过来立起即可。

## 表面处理：不留打印纹
模型本身已经为"看不到层纹"做了设计，再配合下面的切片设置：

**模型上做的**
- **篮子外壁：自带藤编纹**（`WEAVE_*` 参数）。纹理刻入 0.6 mm，编条宽约 2 mm（约等于 10 层），
  横竖交替，层纹和 Z 缝都会被纹理吃掉，看不出来。
- **侧框：截面改为带 0.8 mm 倒角的扁条**。平放打印时，四周都是竖直的墙，没有圆管那种台阶纹；
  倒角是 45°，打印出来很干净。轮子外缘也做了倒角。
- 篮子底面、侧框底面贴打印板，用**纹理 PEI 板**会得到统一的磨砂面。

**切片设置（Bambu Studio / OrcaSlicer）**
| 项目 | 篮子 | 侧框 |
|---|---|---|
| 层高 | 0.12 | 0.16 |
| 墙层数 | 3 | 3 |
| 外墙速度 | ≤ 60 mm/s | ≤ 60 mm/s |
| 墙打印顺序 | 内墙→外墙 | 内墙→外墙 |
| Z 缝位置 | 后方（藤编纹会把它盖住） | 对齐，放在内侧 |
| 熨烫 (Ironing) | 关 | **开：仅最顶层** |
| 模糊皮肤 (Fuzzy skin) | **关**（会把藤编纹糊掉） | 可选：想要磨砂质感时打开，厚度 0.2 |
| 打印板 | 纹理 PEI | 纹理 PEI |
| 填充 | 15% | 20% |

建议用**哑光 PLA（Matte PLA）**：哑光料本身就能显著弱化层纹，颜色可以选奶油色、薄荷绿。
侧框长 200 mm，床小于 200 mm（如 A1 mini 180×180）时斜着摆放就能放下。

## 配合松紧（唯一可能要调的）
- 插不进去：`build_cart.py` 里 `HOLE_D` 改成 4.3
- 太松会掉：改成 4.1，或者在孔里点一滴胶（给小孩玩建议点胶，更安心）

改完运行 `python3 build_cart.py` 重新生成（依赖：`pip install manifold3d trimesh numpy scipy`）。
总高、篮子尺寸、层高 `LEVELS`、立柱粗细都在脚本开头。

预览图用 `node render3d.js stl/assembly_preview.glb out.png` 渲染（Playwright + three.js）。
