`stl/` 中的零件都已摆好打印朝向，直接拖进切片软件即可。

| 文件 | 数量 | 尺寸 (mm) | 说明 |
|---|---|---|---|
| basket_x3.stl  | 3 | 124.5×86.5×24 | 篮子，四角带上下插孔，开口朝上打印 |
| spacer_x8.stl  | 8 | Ø10×61 | 层间立柱，两端自带插销，竖着打印 |
| handle_x2.stl  | 2 | 85×18×9 | 弧形把手，平面贴床打印 |
| caster_x4.stl  | 4 | Ø11×19 | 脚轮叉，倒置打印（插孔面贴床） |
| wheel_x4.stl   | 4 | Ø13×5 | 轮子 |
| dowel_x8.stl   | 8 | Ø6×14.5 | 插销：连接 脚轮↔底篮、顶篮↔把手 |

## 打印建议
PLA，层高 0.16–0.2，喷嘴 0.4，填充 15–20%，不需要支撑。插销和立柱可以用 3 圈壁，强度更好。

## 组装顺序
1. 轮子放进脚轮叉，剪一段 **1.75 mm 耗材**（约 12 mm）当轮轴穿过去，两端用烙铁或打火机稍微烫一下压扁防脱。
2. 4 根插销插入脚轮顶部插孔，再插进底层篮子底部的四角插孔。
3. 底层篮子顶部插 4 根立柱 → 套上中层篮子 → 再插 4 根立柱 → 套上顶层篮子。
4. 顶层篮子四角插入插销，两个把手分别装在两个短边上。

## 配合松紧
插孔 Ø6.2 / 插销 Ø6.0。打印机偏紧装不进去时，把 `build_cart.py` 里的 `HOLE_D` 改成 6.3；
太松就改成 6.1，或者点一滴胶水。改完运行 `python3 build_cart.py` 重新生成
（依赖：`pip install manifold3d trimesh numpy scipy`）。
总高、篮子尺寸、层间距这些也都是脚本顶部的参数。
